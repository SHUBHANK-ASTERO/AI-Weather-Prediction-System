# 🌦️ AI Weather Prediction System — Version 2

A Python and Machine Learning weather classification application for an AICTE Machine Learning & AI internship project.

## New features
- Weather prediction using Random Forest
- Prediction confidence/probabilities
- Dataset explorer
- Weather class distribution
- Average weather measurements
- Feature relationship chart
- Comparison of Random Forest, Decision Tree, Logistic Regression and KNN
- Random Forest feature importance
- City label in the interface
- Streamlit web interface

## Run
```bash
python -m pip install -r requirements.txt
python app.py
python -m streamlit run app.py
```

## Important
The included CSV is an illustrative sample dataset created to make the project runnable. For an academic/internship submission, replace it with a genuine weather dataset and cite its source. Do not claim the sample model's accuracy represents real-world weather forecasting.

## Suggested next upgrade
Connect a genuine historical weather dataset or weather API, then retrain and document the model's real evaluation results.
